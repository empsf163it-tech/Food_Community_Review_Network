- Removed numbered section/step labels from the visual UI.
- Services now use a photographic 2×2 card layout with food-related background images.
- Login and Sign Up are standalone pages with no navbar/footer.
- Login and Sign Up logos are centered inside the form card and use a dimensional food/table SVG mark.
- Contact page keeps only the requested contact block, form, social icons and map; extra placeholder/support sections removed.
- Non-home H1 headings remain centered.

- Dashboard remains a single standalone page with logout.
- Responsive at mobile, tablet and desktop widths.
